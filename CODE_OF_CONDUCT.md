# Code of Conduct

## Our Pledge

We as contributors and maintainers of **CTFVault** pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

This list exists to help people get into security — from someone who's never used a terminal to someone chasing their next CVE. Questions from beginners are as welcome here as link fixes from veterans.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Being respectful of differing opinions, viewpoints, and experience levels
- Giving and gracefully accepting constructive feedback on PRs and issues
- Focusing on what's best for people using this list to learn
- Helping newcomers figure out where to start

Examples of unacceptable behavior:

- Harassment, insults, or derogatory comments — public or private
- Gatekeeping — mocking someone for not knowing a tool, a category, or where to begin
- Trolling, deliberately disruptive or bad-faith contributions
- Publishing others' private information without explicit permission
- Any conduct which could reasonably be considered inappropriate in a professional setting

## Scope

This applies within all project spaces — issues, pull requests, discussions — and when someone is officially representing the project elsewhere (e.g. posting about CTFVault on Reddit or Discord).

## Responsible Use of Linked Resources

CTFVault links to third-party platforms and vulnerable-by-design labs. We ask contributors and users to:

- Only submit resources that are legal to use and intended for security training
- Not use this list to request help attacking real-world, non-consenting targets
- Respect each linked platform's own terms of service and rules of engagement

Contributions that primarily serve unauthorized access, fraud, or harming others will be rejected. See the README's [note on using these resources responsibly](README.md#a-note-on-using-these-responsibly).

## Enforcement

Report unacceptable behavior by opening an issue tagged `conduct`, or by contacting the maintainer directly via GitHub ([@arif-offsec](https://github.com/arif-offsec)).

Project maintainers have the right to remove, edit, or reject comments, commits, issues, and other contributions not aligned with this Code of Conduct, and may temporarily or permanently ban any contributor for behavior they deem inappropriate, threatening, or harmful.
