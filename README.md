## About

CTFVault is a curated, deduplicated directory of free CTF platforms, wargames, vulnerable labs, and challenge archives — sorted by subject (Web, Crypto, Pwn, Forensics, Active Directory, Cloud, Mobile, and more) and tagged 🟢 Beginner, 🟡 Intermediate, or 🔴 Advanced within each category, so you can find your actual starting point instead of scrolling a flat list.

"Free" gets stretched to mean a lot of different things across this space, so the list is split into two files on purpose:

| File | What's in it |
|---|---|
| 🟢 **[README-free.md](README-free.md)** | **100% free.** Everything in here is usable in full for $0 — no subscription, no paid tier gatekeeping the core challenges, no "free sample" of something paid. **Start here.** |
| 🟡 **[README-freemium.md](README-freemium.md)** | **Freemium / free-tier only.** Genuinely good platforms (TryHackMe, Hack The Box, PentesterLab, and others) with real free content — but a paywall somewhere in the full catalogue. Kept separate so the two are never confused. |

No list like this stays perfectly current — CTF sites appear, disappear, and change pricing constantly. If a link is dead or a platform's pricing has changed, please open a PR. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Where to Start

New to this? Open **[README-free.md](README-free.md)** and its [Table of Contents](README-free.md#table-of-contents) — pick a category (Web, Pwn, Crypto, AD, Cloud, Mobile, and more), then pick the 🟢 Beginner tier inside it. That file is the authoritative, up-to-date breakdown of every category — this page intentionally doesn't duplicate it, so there's only one place that can go out of date.

## Using These Responsibly

Only attack targets you're explicitly authorized to test, run downloaded vulnerable VMs on an isolated network, and watch for real cloud-provider charges on cloud-based labs. See the full [note on using these resources responsibly](README-free.md#a-note-on-using-these-responsibly) for details.
